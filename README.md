# Family Tree Application (Java)

Консольное Java-приложение для построения и управления генеалогическим деревом. Проект реализован с использованием объектно-ориентированного подхода и архитектуры **MVP (Model-View-Presenter)**.

---

## 📌 Описание

Программа позволяет:
- Создавать и сохранять дерево семьи
- Добавлять новых членов и связи между ними
- Просматривать дерево и редактировать информацию
- Сохранять и загружать данные через файловое хранилище

---

## 🧱 Архитектура

- **Model (`familyTree/`)** — классы, представляющие членов семьи и структуру дерева  
- **View (`ConsoleUi.java`, `View.java`)** — пользовательский интерфейс через консоль  
- **Presenter (`Presenter.java`)** — логика взаимодействия между моделью и представлением  
- **Service (`service_tree/`)** — обработка дерева, логика добавления и поиска  
- **FileHandler (`file_handler/`)** — сохранение и загрузка данных
